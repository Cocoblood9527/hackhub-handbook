# Hackhub Handbook (可交互 HTML / Interactive HTML)

《Hackhub》游戏内置手册（Handbook）的完整整理版，中英双语可交互网页。单文件复刻游戏内 Handbook 窗口外观，**顶部搜索栏真实可用**（全文检索 + 命中高亮 + 结果摘要），左侧栏文章导航、分类卡片、面包屑均可点击，无需联网、双击即用。

Interactive web editions of the in-game Handbook from **Hackhub**, in Simplified Chinese & English. Each is a single offline file that mirrors the game window with a **working search bar** (full-text search, highlighted hits, result excerpts). Sidebar article navigation, category cards and breadcrumbs are all clickable — no network needed, just open the file.

## 内容 Contents

- 8 个章节：账户 / 挖掘 / Metasploit / 脚本编写 / 怀疑 / 终端命令 / Python 模块 / Online World
  8 categories: Accounts / Digging / Metasploit / Scripting / Suspicion / Terminal Commands / Python Modules / Online World
- 89 篇文章，全文完整提取，内容与游戏内文本逐字一致；部分文章游戏内简体中文本身未翻译（显示英文），与游戏保持一致
  89 articles, extracted in full and verbatim with the in-game text; some articles are left untranslated (English) in the game's own Simplified Chinese build, and are kept identical to the game here
- 支持按标题和正文全文搜索，命中词高亮并显示结果摘要；URL 带锚点，可直达某篇文章（如 `#art-<id>`、`#cat-<分类>`）
  Full-text search over titles and bodies with hit highlighting and result excerpts; hash anchors in the URL link straight to an article or category (e.g. `#art-<id>`, `#cat-<Category>`)
