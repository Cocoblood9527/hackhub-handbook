# Hackhub Handbook (可交互 HTML)

《Hackhub》游戏内置手册（Handbook）的完整整理版，中英双语可交互网页。单文件复刻游戏内 Handbook 窗口外观，**顶部搜索栏真实可用**（全文检索 + 命中高亮 + 结果摘要），左侧栏文章导航、分类卡片、面包屑均可点击，无需联网、双击即用。

Interactive web editions of the in-game Handbook from **Hackhub**, in Simplified Chinese & English. Each is a single offline file that mirrors the game window with a **working search bar** (full-text search, highlighted hits, result excerpts). Sidebar article navigation, category cards and breadcrumbs are all clickable — just open the file.

## 内容 Contents

- 8 个章节 categories：账户 Accounts / 挖掘 Digging / Metasploit / 脚本编写 Scripting / 怀疑 Suspicion / 终端命令 Terminal Commands / Python 模块 Python Modules / Online World
- 89 篇文章 articles，全文完整提取，内容与游戏内文本逐字一致；部分文章游戏内简体中文本身未翻译（显示英文），与游戏保持一致
- 支持按标题和正文全文搜索，命中词高亮并显示结果摘要；URL 带锚点，可直达某篇文章（如 `#art-<id>`、`#cat-<分类>`）

## 文件 Files

| 文件 | 说明 |

> 使用方法：点击文件名 → Code 页面上的 **Raw**（或下载按钮）保存到本地，再用浏览器打开。GitHub 网页内直接预览 `.html` 只会显示源码。
> Usage: open the file's page, save it locally via **Raw**, then open it in a browser — GitHub previews `.html` as source code only.
